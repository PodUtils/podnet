# The class of each sh block of README.md and docs/*.md (scripts/doc-commands.py).
# FILE HASH CLASS REASON. CLASS: run, scenario, live, live-manual, root or skip. A
# reason that starts with [needs TOOL,TOOL] names the programs that a block needs
# besides podnet. A scenario block has its set-up in scripts/doc-scenarios/HASH.sh;
# a live or root block can have one. live.yml runs the live and root blocks; a
# live-manual block needs what the runner does not have.
