# podnet-core

`podnet-core` is the core layer of
[podnet](https://github.com/PodUtils/podnet): the process, the files, the
state, the reports and the supervisor of detached instances. The other
crates of podnet use it. It does not use them.

It is a library of podnet, not a stable interface. Use the crate `podnet`.
