A prerelease of `podnet`, for tests. It follows v0.4.0-beta.7.

## Binaries

| File | System |
| --- | --- |
| `podnet-x86_64-unknown-linux-musl` | Linux x86-64 |
| `podnet-aarch64-unknown-linux-musl` | Linux ARM64 |
| `podnet-armv7-unknown-linux-musleabihf` | Linux ARMv7 (32-bit, hard float) |
| `podnet-arm-unknown-linux-musleabihf` | Linux ARMv6 (32-bit, hard float) |
| `podnet-i686-unknown-linux-musl` | Linux x86 (32-bit) |
| `podnet-riscv64gc-unknown-linux-musl` | Linux RISC-V 64 |
| `podnet-loongarch64-unknown-linux-musl` | Linux LoongArch64 |
| `podnet-powerpc64le-unknown-linux-musl` | Linux POWER, little-endian |

Each binary is static (musl). It needs no C library on the host.
`podnet.1` is the manual page. `llms.txt` and `llms-full.txt` are the
manual and the documents as plain text. `SHA256SUMS` lists each file.

The image is `ghcr.io/podutils/podnet:v0.4.0-beta.8` (also `:beta`).

## Check a download

```sh
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify podnet-x86_64-unknown-linux-musl --repo PodUtils/podnet
cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity https://github.com/PodUtils/podnet/.github/workflows/release.yml@refs/tags/v0.4.0-beta.8 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sh scripts/rebuild.sh v0.4.0-beta.8   # rebuild and compare (x86_64, aarch64)
```

`podnet update` does the first three checks itself.

## Breaking

* New exit codes: 66 (a file that must exist is missing), 68 (a peer
  address does not resolve), 71 (a file of the host cannot be used: a key or
  an allow list with a wide mode), 77 (a peer that the allow list does not
  hold) (T-261).
* `podnet doctor --ssh-relay HOST:PORT` dials through `--connect-proxy`, else
  through the proxy of the process (`HTTPS_PROXY`, `NO_PROXY`). Before, the
  flag path dialed direct. A proxy that the probe cannot use is a `fail` row
  (T-322).
* `podnet ssh-relay --service sandhole` asks for the remote port 80 (the fact
  of the relay). `--remote-port` overrides the fact (T-319).

## Changes for a tester

* `podnet link`: a link between two installs of podnet (T-261 to T-267,
  `docs/link.md`). `link listen`, `dial`, `connect`, `status`, `close` and
  `carriers`; the unix and memory carriers; a key for each install with its
  fingerprint and a default-deny allow list; a hello that proves both keys
  before any service (on the unix and memory carriers only); a resume of 10
  minutes over `pod-session`; a control socket (mode 0600, a token) with
  `status`, `close-link`, `close-stream`, `select` and `dump`
  (T-307, T-309); `peer:FINGERPRINT/SERVICE` as a network of `forward -L`
  (T-266); Cargo features for the optional carriers (T-311).
* Networks: `turn://HOST[:PORT]` and `turns://HOST[:PORT]`, a TURN relay for
  UDP flows (`forward -L udp:...`, the router); the account comes from
  `PODNET_TURN_USER` and `PODNET_TURN_PASSWORD_FILE` (T-321).
* `podnet ssh-relay` and its doctor probe log in with the methods that the
  relay offers (the key, `none`, an empty keyboard-interactive) and verify an
  RSA host key (T-318).
* `podnet bug-report --include-link` adds the redacted state of each running
  link (T-309).
* The tests: fixes of three flaky tests (T-316, T-324) and of the WebSocket
  step of `live` (T-323).
* podnet takes the crates of `PodUtils/podcrates` at v0.33.0 (T-137).

## What to report

Open an issue in `PodUtils/podnet` with the output of `podnet doctor --json`
and `podnet pod doctor --json`, the command, and the stderr of the command
with `-v`. The test guide is GitHub #89.

## Limits

* This is a beta. Each item of Breaking can change again before the stable
  release.
* No crates.io release of `podnet` exists.
* The Rekor inclusion proof is not checked by `podnet update`.
* `rsa` 0.10.0-rc.18 (pinned by russh) has the advisory RUSTSEC-2023-0071, a timing
  leak of an RSA private key. podnet makes Ed25519 keys. Give podnet no RSA key (T-326).
* `podnet link` has the unix and memory carriers only; the carriers that
  cross a network (TCP with TLS and the others) come with `pod-link` of
  podcrates. The hello of a link binds no stream: it is for these local
  carriers only.
* Not measured against a live service: a TURN server, Serveo,
  localhost.run, Pinggy and Sandhole.
* The limits of v0.4.0-beta.7 stand.
