A prerelease of `podnet`, for tests. It follows v0.4.0-beta.10.

## Binaries

| File | System |
| --- | --- |
| `podnet-x86_64-unknown-linux-musl` | Linux x86-64 |
| `podnet-aarch64-unknown-linux-musl` | Linux ARM64 |
| `podnet-armv7-unknown-linux-musleabihf` | Linux ARMv7 (32-bit, hard float) |
| `podnet-arm-unknown-linux-musleabihf` | Linux ARMv6 (32-bit, hard float) |
| `podnet-i686-unknown-linux-musl` | Linux x86 (32-bit) |
| `podnet-riscv64gc-unknown-linux-musl` | Linux RISC-V 64 |
| `podnet-loongarch64-unknown-linux-musl` | Linux LoongArch64 |
| `podnet-powerpc64le-unknown-linux-musl` | Linux POWER, little-endian |

Each binary is static (musl). It needs no C library on the host.
`podnet.1` is the manual page. `llms.txt` and `llms-full.txt` are the
manual and the documents as plain text. `pod-report.schema.json` is the JSON
Schema of `podnet pod --report`. `SHA256SUMS` lists each file.

The image is `ghcr.io/podutils/podnet:v0.4.0-beta.11` (also `:beta`).

## Check a download

```sh
sha256sum -c SHA256SUMS --ignore-missing
gh attestation verify podnet-x86_64-unknown-linux-musl --repo PodUtils/podnet
cosign verify-blob --bundle SHA256SUMS.sigstore.json \
  --certificate-identity https://github.com/PodUtils/podnet/.github/workflows/release.yml@refs/tags/v0.4.0-beta.11 \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com SHA256SUMS
sh scripts/rebuild.sh v0.4.0-beta.11   # rebuild and compare (x86_64, aarch64)
```

`podnet update` does the first three checks itself.

## Breaking

* The route announcement of the mesh of `podnet link` is version 2: each hop names its next node. A node refuses an
  announcement of version 1 (podnet 0.4.0-beta.10 and older): update each node of a mesh (T-346).
* `podnet send` and `podnet receive` take the transit key from the wormhole (`derive_key`, as magic-wormhole does). A
  file or a directory does not move between this release and 0.4.0-beta.10 or older; the new end says "update podnet at
  both ends". A text moves as before (T-103).
* `podnet receive` refuses a zip that is larger than the offer that the person accepted (T-341).
* A proxy on a unix socket whose path starts with `//HOST` or holds `@` (`socks5h+unix://user:pass@x`) exits 64. Before,
  the path was taken as written and a password in it showed in each line that named the proxy (T-349).
* `podnet pod --backend seccomp`: a raw socket gets `EPERM` by default; `--allow-raw icmp` opens a raw ICMP socket only.
  `AF_PACKET`, `AF_XDP` and `SOCK_PACKET` get `EPERM` in each mode. A ping socket works as before (T-334, T-350).

## Changes for a tester

* `podnet wg serve --config FILE`: a userspace WireGuard responder with several peers; each inner TCP and UDP flow goes
  to `--egress`. A peer has a share of the flows (`--peer-flows`, `--peer-udp-flows`) (T-125, T-345).
* `wg:FILE`: `PresharedKey` (T-337); a chain `wg:FILE over warp` for a host with no UDP; names at the `DNS` of the file
  (T-117).
* The transfer moves a file and a directory to and from the Python magic-wormhole (T-103, T-106); `podnet send --words N`
  (T-338); the podnet relay (`--relay-pair`) and a piping server (`--piping URL`) as transits (T-104, T-252).
* `relay node --resume --seal` and `relay connect --resume --seal`: an end-to-end channel above the resumable layer; the
  relay sees sealed records only (T-087).
* The router: kernel mode probes each WAN through its own table; the MSS clamp now changes the MSS on the wire (two
  defects of its rule were fixed); a guest wire on a veth end (`veth:NAME`) (T-120, T-248).
* Fixes of a security review of the code of peer input (T-341 to T-347) and of two crashes that the fuzz run found
  (T-348, T-349). Eight new fuzz targets cover the parsers of peer input (T-339).
* `wg:FILE` and the vnet dialer take a UDP port from the stack (port 0); podnet's own port picker is gone (T-117).
* The listener of a `dns`, `icmp`, `udp` or `ws` link gives exit 77 to a dialer that refuses the key of the listener
  (tested at the library) (T-273, T-278).
* A proxy password in a tool's file (for example `~/.gitconfig`) no longer shows in a log line at `RUST_LOG=info` (T-349).
* The shared crates of PodUtils/podcrates are at `v0.45.0` (T-137).

## What to report

Open an issue in `PodUtils/podnet` with the output of `podnet doctor --json`
and `podnet pod doctor --json`, the command, and the stderr of the command
with `-v`. The test guide is GitHub #89.

## Limits

* This is a beta. Each item of Breaking can change again before the stable
  release.
* No crates.io release of `podnet` exists.
* The Rekor inclusion proof is not checked by `podnet update`.
* `rsa` 0.10.0-rc.18 (pinned by russh) has the advisory RUSTSEC-2023-0071, a timing
  leak of an RSA private key. podnet makes Ed25519 keys. Give podnet no RSA key (T-326).
* IPv6 is outside the guards of the router's kernel mode: podnet warns when the host forwards IPv6 (T-347).
* Not measured against a live service: a WireGuard peer of another code base for `wg serve`, and a real host with no UDP.
* The limits of v0.4.0-beta.10 stand, except the transfer of a file with the Python client, which this release adds.
